# Applied SAP Finance — AFP6 Financial Planning & Performance

> **Finance Architecture Stream: AFP6 | Financial Planning & Performance | Enterprise Financial Planning**

## North Star

Design FP&A so leaders can move from **annual budgeting to continuous, driver-based, scenario-aware and increasingly intelligent planning**.

## Master Value Stream

`Strategy → Drivers → Plan → Budget → Forecast → Actuals → Variance → Scenario → Decision → Replan`

## Core Architecture Lens

FP&A connects:

- **Strategy:** goals, priorities, targets, strategic initiatives
- **Business:** revenue, demand, workforce, supply, operations, investment
- **Finance:** budgets, forecasts, actuals, variance, management reporting
- **Data:** master data, actuals, drivers, assumptions, external signals
- **Technology:** SAP S/4HANA, SAP Analytics Cloud, data platforms, integrations
- **AI:** predictive forecasting, anomaly detection, scenario generation, intelligent recommendations

## Architecture Outcomes

By the end of the journey, the learner should be able to:
1. Explain modern FP&A and its relationship with Finance and enterprise strategy.
2. Design driver-based planning, budgeting, forecasting, scenario planning, and performance management.
3. Architect SAP Analytics Cloud Planning with S/4HANA and connected enterprise data.
4. Design planning governance, workflows, versions, controls, and data quality.
5. Diagnose planning and forecasting issues through data, model, calculation, process, and governance evidence.
6. Design AI opportunities for predictive and autonomous planning.
7. Produce a target-state Enterprise Financial Planning architecture and transformation roadmap.

## Core SAP Ecosystem

Typical solution components may include **SAP Analytics Cloud Planning, SAP S/4HANA, SAP Datasphere, SAP Integration Suite, SAP Business AI/Joule, SAP Analytics Cloud analytics, enterprise data platforms, and connected business planning sources**.
