# Applied SAP Finance — APT2 Procure to Pay

> **Finance Architecture Stream: APT2 | Procure to Pay | Autonomous Finance**

## North Star

Design P2P so that every unit of external spend is **visible, authorized, matched, controlled, payable, auditable, and increasingly autonomous**.

## Master Value Stream

`Demand → Requisition → Approval → Purchase Order → Confirmation → Receipt/SES → Invoice → Match → Liability → Payment → Clearing → Reconciliation → Insight`

## Core Architecture Lens

The learner connects the **business flow** and the **financial flow**:

- Business: need → requisition → PO → fulfillment → invoice → payment
- Finance: commitment → receipt/accrual evidence → AP liability → tax → cash disbursement → clearing → reporting

## Architecture Outcomes

By the end of the journey, the learner should be able to:
1. Explain end-to-end P2P and its finance impact.
2. Architect Procurement, AP, Treasury, Tax, GL, supplier collaboration, and analytics together.
3. Design three-way-match and service-entry controls.
4. Diagnose P2P failures through document flow, accounting impact, master data, and integration evidence.
5. Design automation, exception management, and AI-assisted P2P.
6. Define KPIs such as cycle time, first-pass match rate, exception rate, touchless processing, DPO, and duplicate-payment exposure.
7. Produce a target-state P2P architecture and transformation roadmap.

## Core SAP Ecosystem

Typical solution components may include **SAP S/4HANA, SAP Fiori, SAP Business Network, SAP Ariba, SAP Integration Suite, SAP Analytics Cloud, workflow/automation services, tax services, banks/payment providers, and intelligent document processing**.
