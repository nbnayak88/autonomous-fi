# Applied SAP Finance — ACC7 Controlling & Profitability

> **Finance Architecture Stream: ACC7 | Controlling & Profitability | Cost & Profitability Excellence**

## North Star

Design Management Accounting so leaders can understand **where money is consumed, where value is created, what drives cost and margin, and what decisions can improve profitability**.

## Master Value Stream

`Cost Capture → Cost Object → Allocation/Settlement → Costing → Actual vs Plan → Variance → Margin → Profitability → Decision → Improvement`

## Core Architecture Lens

Controlling connects:

- **Business:** products, services, customers, channels, projects, plants, operations
- **Finance:** actuals, planning, allocations, close, reporting
- **Management Accounting:** cost centers, profit centers, internal orders, product costing, profitability
- **Data:** cost drivers, master data, transactional data, operational drivers
- **Technology:** SAP S/4HANA Controlling, Analytics Cloud, Datasphere, integration
- **AI:** predictive cost, margin forecasting, anomaly detection, intelligent allocations, decision recommendations

## Architecture Outcomes

By the end of the journey, the learner should be able to:
1. Explain Management Accounting and its relationship with Financial Accounting.
2. Design cost-center, profit-center, internal-order, product-costing, and profitability capabilities.
3. Architect integrated cost and profitability processes in SAP S/4HANA.
4. Design allocations, settlements, controls, period-close activities, and management reporting.
5. Diagnose cost and profitability issues using transaction, master-data, allocation, integration, and accounting evidence.
6. Design AI opportunities for predictive cost and profitability management.
7. Produce a target-state Cost & Profitability architecture and transformation roadmap.

## Core SAP Ecosystem

Typical solution components may include **SAP S/4HANA Controlling, Product Costing, Profitability Analysis, SAP Analytics Cloud, SAP Datasphere, SAP Integration Suite, SAP Business AI/Joule, and connected operational applications**.
