# Finance Ecosystem Reference

The finance architecture is ERP-agnostic and ecosystem-oriented.

## Example Platforms

| Capability | Example Platforms |
|---|---|
| Core ERP | SAP S/4HANA, Oracle ERP, Microsoft Dynamics 365 |
| AP | SAP FI-AP, Ariba, Coupa |
| AR | SAP FI-AR, Oracle Receivables |
| Tax | SAP DRC, Vertex, Avalara |
| Treasury | SAP Treasury, Kyriba, GTreasury |
| Planning | SAP Analytics Cloud, BPC, Anaplan |
| Controlling | SAP S/4HANA CO, Oracle EPM |
| Consolidation | SAP Group Reporting, Oracle consolidation |
| GRC | SAP GRC, AuditBoard, ServiceNow GRC |
| Analytics | SAP Analytics Cloud, Tableau, Power BI |
| AI | SAP Business AI, Joule, SAP Build, Automation Anywhere |
| Integration | SAP Integration Suite, MuleSoft, Boomi |
| Banking | Banks, payment networks, host-to-host platforms |
| Compliance | Tax, e-invoicing and regulatory platforms |
