# Finance Ecosystem

Autonomous Finance is an ecosystem architecture, not an ERP-only architecture.

## Ecosystem Domains

- ERP and core finance
- Procurement and AP
- Billing and AR
- Tax and e-invoicing
- Banking and payments
- Treasury and risk
- Planning and performance
- Consolidation and close
- GRC and controls
- Analytics and data
- AI and automation
- Integration and API platforms

## Architecture Principle

Select platforms based on capability fit, process fit, integration fit, data ownership, controls, experience, total cost, scalability and strategic alignment.
