# Finance Value Streams

## 1. Record to Report
Transaction → Close → Consolidate → Report → Insight

## 2. Procure to Pay
Need → Source → Buy → Receive → Invoice → Pay → Reconcile

## 3. Order to Cash
Order → Deliver → Bill → Collect → Reconcile → Resolve

## 4. Tax Compliance
Capture → Determine → Calculate → File → Report → Audit

## 5. Treasury & Risk
Forecast → Liquidity → Fund → Transact → Hedge → Monitor → Control

## 6. Plan to Perform
Plan → Budget → Forecast → Simulate → Execute → Analyze

## 7. Cost to Profit
Capture Cost → Allocate → Analyze → Optimize → Improve Margin

## 8. Asset Lifecycle
Acquire → Capitalize → Operate → Depreciate → Transfer → Retire

## 9. Governance to Assurance
Identify Risk → Control → Test → Monitor → Remediate → Assure

## 10. Insight to Decision
Collect → Analyze → Explain → Decide → Act → Measure

## 11. Intelligence to Autonomy
Detect → Predict → Recommend → Approve → Act → Learn

## 12. Connect to Orchestrate
Event → Integrate → Transform → Validate → Route → Reconcile → Observe
